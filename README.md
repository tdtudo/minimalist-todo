# ToDo_list - 桌面待办清单

一个极简风格的桌面待办清单应用，采用透明毛玻璃效果，像桌面小组件一样始终显示在桌面上。

## 功能特性

### 任务管理
- **添加任务** - 输入内容后按 Enter 或点击添加按钮
- **批量添加** - 使用分号 `;` 或 `；` 分隔，一次添加多个任务
- **完成任务** - 点击左侧复选框标记完成，已完成任务自动移到底部
- **删除任务** - 悬停显示删除按钮，点击即可删除
- **编辑任务** - 双击任务文字进入编辑模式
- **拖拽排序** - 拖动任务条目自由调整顺序

### 标签系统
- **标签分类** - 为每个任务添加标签，方便分类管理
- **标签筛选** - 点击顶部标签按钮快速筛选对应任务
- **标签窗口** - 将标签拖出窗口外，自动创建独立的标签筛选窗口
- **标签记忆** - 自定义标签自动保存，添加时可从下拉列表快速选择
- **智能联动** - 主窗口与标签窗口数据实时同步，已打开标签窗口的任务在主窗口自动隐藏

### 窗口控制
- **无边框设计** - 极简美观，拖动标题栏移动窗口
- **锁定位置** - 单击左上角绿色按钮锁定窗口位置，防止误拖
- **窗口置顶** - 双击左上角绿色按钮切换始终置顶（置顶时按钮变红并带发光效果）
- **最小化到托盘** - 点击黄色按钮最小化到系统托盘，不占用任务栏
- **关闭确认** - 点击红色按钮弹出确认对话框，可选择最小化到托盘或关闭应用，支持"不再询问"
- **单实例运行** - 防止重复打开，重复启动时自动聚焦已有窗口

### 系统托盘
- **托盘图标** - 最小化后常驻系统托盘
- **点击切换** - 左键点击托盘图标显示/隐藏窗口
- **开机自启** - 右键托盘菜单可设置开机自动启动（默认静默启动）
- **快速退出** - 右键托盘菜单可直接退出应用

### 个性化设置
- **语言切换** - 支持中文 / English
- **背景颜色** - 7 种预设颜色 + 调色盘自由选色 + 自定义颜色值输入
- **背景图片** - 上传本地图片作为窗口背景
- **透明度调节** - 滑块自由调节背景不透明度（0% ~ 100%）
- **字体颜色** - 自定义字体颜色，适配不同背景

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + N` | 打开添加任务面板 |
| `Enter` | 确认添加任务 |
| `Esc` | 关闭添加面板 |

## 安装使用

### 便携版（推荐）
1. 双击 `ToDo_list 1.0.0.exe`
2. 无需安装，直接运行
3. 可放在任意位置（桌面、U盘等）

### 安装版
1. 双击 `ToDo_list Setup 1.0.0.exe`
2. 选择安装路径
3. 完成安装后自动创建桌面快捷方式和开始菜单快捷方式

## 操作指南

### 窗口控制按钮（左上角）

| 按钮 | 颜色 | 操作 | 功能 |
|------|------|------|------|
| 关闭 | 🔴 红色 | 单击 | 弹出关闭确认对话框 |
| 最小化 | 🟡 黄色 | 单击 | 最小化到系统托盘 |
| 锁定/置顶 | 🟢 绿色 | 单击 | 锁定/解锁窗口位置 |
| 锁定/置顶 | 🟣 紫色 | 单击 | 已锁定状态，再次点击解锁 |
| 锁定/置顶 | 🔴 红色发光 | 双击 | 切换窗口始终置顶 |

### 右上角按钮

| 按钮 | 功能 |
|------|------|
| ⚙️ | 打开设置窗口 |
| ＋ | 打开/关闭添加任务面板 |

### 添加任务
1. 点击右上角 **＋** 按钮或按 `Ctrl + N`
2. 输入任务内容（可使用分号批量添加：`任务1;任务2;任务3`）
3. 可选填标签，若当前在标签筛选窗口中则自动使用当前标签
4. 按 `Enter` 或点击"添加"按钮

### 标签窗口
1. 将顶部标签按钮拖出窗口边界
2. 释放鼠标，自动在释放位置创建独立的标签筛选窗口
3. 标签窗口与主窗口数据实时同步
4. 关闭标签窗口后，该标签任务在主窗口恢复显示

### 设置
1. 点击右上角 **⚙️** 按钮打开设置窗口
2. 左侧选择设置分类（语言 / 背景）
3. 修改设置后实时生效

## 数据存储

| 数据类型 | 存储位置 |
|---------|---------|
| 任务数据 | `%APPDATA%\my-todo-app\todos.json` |
| 应用设置 | 浏览器 localStorage |

所有数据自动保存，无需手动操作。
